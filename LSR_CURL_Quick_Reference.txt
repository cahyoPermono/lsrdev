LSR API - CURL QUICK REFERENCE
===============================

BASE_URL="http://localhost:8000/api"
TOKEN="your_bearer_token_here"

===============================================================================
BASIC COMMANDS
===============================================================================

# 1. LOGIN (Get Token)
curl -X POST "$BASE_URL/auth/login" \
  -H "tokenmedco: your_tokenmedco_here" \
  -F "email=your-email@contractor.medcoenergi.com"

# 2. GET ALL COMPANIES
curl -X GET "$BASE_URL/lsr/companies" \
  -H "Authorization: Bearer $TOKEN"

# 3. GET ALL SUBMISSIONS
curl -X GET "$BASE_URL/lsr/submissions" \
  -H "Authorization: Bearer $TOKEN"

# 4. CREATE SUBMISSION (Simple)
curl -X POST "$BASE_URL/lsr/submissions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "company": 1,
    "block": 1,
    "area_field": 1,
    "location": 1,
    "function": 1,
    "ptw_number": "PTW-2024-005",
    "activity_description": "New electrical work",
    "categorys": [1, 2],
    "start_work_verifier_id": 1
  }'

# 5. CREATE SUBMISSION (With Questionnaires)
curl -X POST "$BASE_URL/lsr/submissions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "company": 1,
    "block": 1,
    "area_field": 1,
    "location": 1,
    "function": 1,
    "ptw_number": "PTW-2024-006",
    "activity_description": "Electrical maintenance with safety checks",
    "categorys": [1, 2],
    "start_work_verifier_id": 1,
    "questionnaires": [
      {
        "question_number": "Q001",
        "compliance_st1": true,
        "deviation_st1": "No deviation",
        "compliance_st2": true,
        "deviation_st2": "No deviation"
      }
    ]
  }'

===============================================================================
FILTERING EXAMPLES
===============================================================================

# Filter by Status
curl "$BASE_URL/lsr/submissions?status=draft" \
  -H "Authorization: Bearer $TOKEN"

# Filter by Work Verifier
curl "$BASE_URL/lsr/submissions?work_verifier_id=1" \
  -H "Authorization: Bearer $TOKEN"

===============================================================================
ONE-LINERS
===============================================================================

# Get submissions (compact output)
curl -s "$BASE_URL/lsr/submissions" -H "Authorization: Bearer $TOKEN" | jq '.data'

# Create and show result
curl -s -X POST "$BASE_URL/lsr/submissions" -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"company":1,"block":1,"area_field":1,"location":1,"function":1,"ptw_number":"PTW-TEST","activity_description":"Test","categorys":[1],"start_work_verifier_id":1}' | jq .

===============================================================================
TROUBLESHOOTING
===============================================================================

# Check server status
curl -I $BASE_URL

# Verbose output (see headers)
curl -v "$BASE_URL/lsr/companies" -H "Authorization: Bearer $TOKEN"

# Test with wrong token (should return 401)
curl "$BASE_URL/lsr/companies" -H "Authorization: Bearer wrong_token"

===============================================================================
SETUP NOTES
===============================================================================

1. Replace BASE_URL with your actual server URL
2. Replace TOKEN with valid bearer token from login
3. Make sure server is running and accessible
4. Check firewall and CORS settings if needed
5. Use jq for better JSON formatting: https://stedolan.github.io/jq/

===============================================================================
SAMPLE WORKFLOW
===============================================================================

# 1. Login to get token
TOKEN=$(curl -s -X POST "$BASE_URL/auth/login" \
  -H "tokenmedco: your_token" \
  -F "email=test@example.com" | jq -r '.data.token.token')

# 2. Use token for API calls
curl "$BASE_URL/lsr/companies" -H "Authorization: Bearer $TOKEN"

# 3. Create submission with token
curl -X POST "$BASE_URL/lsr/submissions" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
